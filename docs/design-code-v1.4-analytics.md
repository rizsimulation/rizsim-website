## Implemented changes

### 1. Class Resources

A non-authorizing original-tab identity travels through the existing first-party launch handoff. The learner click requests focus synchronously and targets the original same-origin Classroom through the existing session channel. The running simulation and selected answers stay intact. Session, target and request identifiers correlate replies. A ready acknowledgement is not misrepresented as foreground focus.

One compact inline retry/reopen fallback replaces the repeated large notification. A newly created empty context from a severed named-tab lookup is closed without touching a loaded tab; missing lookups are not repeatedly reprobed. Reopening Student Classroom is an explicit user action.

### 2. Practice validation

Complete unrecognized codes show exactly `Session not found`, a red whole-field boundary and brief shared circled-cross animation. The submitted code, keyboard focus and selection persist, including through asynchronous workspace refresh. Editing clears the error. Reduced motion removes the animation. The original single secure join call and distinct incomplete, closed, scheduled, expired, Live-only and authorization cases remain unchanged.

### 3. Presenter and Live Responses analytics

All three integrated simulations use the shared presentation extension in `RIZSIM_ANALYTICS_DASHBOARD_CODE.md`. Insight and Systems show valid started records, locked KR, acknowledged LT and completed KG, paired score means/change, matched item transitions, stage-specific source/transfer choices, four response pathways, distributions and within-session group comparisons. Systems uses released server metrics and case-pair denominators, not a client answer key.

Hotel displays actual experimental objectives rather than invented KR/KG grades. Private responses/prices remain sealed until the original release gate passes. Released valid prices use common linear PKR scales, readable A/B median cards, observed dots and n-qualified quartile boxes; min/max whiskers are not confidence intervals.

Native reports, individual results, presenter controls and print/download actions remain available. Live updates retain search text, keyboard focus and selection. The layout prioritizes participation and useful plots, removes repeated headings, constrains a decorative mobile glow, and keeps the minimized live manager away from priority charts. Chart-data summaries are keyboard expandable. Labels, denominators, empty/error states and small-sample cautions are explicit.
